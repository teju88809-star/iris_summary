# iris_summary
This project uses the Iris dataset to calculate descriptive statistics for three measurements: sepal length, sepal width, and petal length.
The summary table includes the mean, median, mode, standard deviation, and 25th, 50th, and 75th percentiles. These statistics help describe each measurement’s center and spread. Comparing the mean with the median can also help identify possible skew.
The analysis was completed in Google Colab using Python, Pandas, and scikit-learn.
